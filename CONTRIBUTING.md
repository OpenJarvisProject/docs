# Contributing

This repo is documentation only — no code lives here. Useful
contributions right now:

- Pointing out where a doc is unclear, inconsistent with another doc,
  or stale relative to an actual decision made elsewhere.
- Filling in a section explicitly marked as open/undecided, if you have
  a concrete proposal — open an issue or PR proposing the change rather
  than editing silently, since these are usually load-bearing decisions
  for work that hasn't started yet.
- Once implementation repos exist, this file will be updated with
  actual code-contribution guidelines.

Keep documentation changes honest about certainty: state what's
actually decided as decided, and what's still open as open. Don't
upgrade a tentative idea to a firm decision just by writing it
confidently.
